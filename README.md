# Campus-Connect
🚀 An all-in-one Campus Event Management System to unify notices, deadlines, registrations, and ticketing. Features role-based access (Admins, Organizers, Students), automated deadline reminders, dynamic event discovery feeds, and QR-based digital ticket generation. Built to replace fragmented campus communication.

## Structure

- `frontend/`: browser application
- `backend/`: server application
- `database/`: schema and migrations
- `infrastructure/`: deployment and infrastructure configuration
- `scripts/`: development and maintenance scripts
- `tests/`: automated tests
- `assets/`: shared static assets
- `docs/`: product, engineering, and deployment documentation

## Getting started

The frontend currently contains a standalone `index.html`. Project-specific setup and run instructions can be added as the application stack is implemented.
